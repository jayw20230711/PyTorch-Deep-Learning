# Deep Learning with PyTorch (Essential Excerpts)


This repository include examples from the book "Deep Learning with PyTorch (Essential Excerpts)" by Eli stevens, Luca Antiga, Thomas Viehmann .
I have saved the coding samples as I follow along the book, so that any one can follow it along the way without the book.
Outputs were saved along with the codes, with details codes I added, for clarity including extra comments and helpfull study 
materials. 

Follow along the order of folders given below:
- Tensor Introduction
- Numeric Types
- Real World Data
- Mechanics of Learning
- NeuralNetwork
